# 铁锈战争存档编辑器

| 界面 | 特点     |
| ---- | -------- |
| IUP  | 原生控件 |
| GOUI | 自绘界面 |
| gowt | 原生控件 |

程序为单文件可执行程序，无需单独安装运行时。可将 `.rwsave` 存档文件路径作为参数打开。

## 使用

### 编辑单个存档

1. 输入存档路径，或点击「…」选择文件。
2. 查看队伍信息，可编辑名称、资金、难度和队伍类型。
3. 点击「自动识别」，将名称符合 `AI - <难度>` 格式、但当前类型为人类的队伍标记为 AI。确认队伍后，点击「保存」写回存档。

写回前会创建同目录下的 `.rwsave.bak` 备份。若该备份已存在，程序会保留它，不会覆盖。

### 批量修复目录

1. 选择存档目录，点击「预览」查看可修复的文件。
2. 确认后点击「处理」修复该目录中的 `.rwsave` 文件。

批量操作只扫描所选目录的当前层级，不递归子目录。每个文件单独处理并保留备份。

## 识别与安全规则

- 仅匹配区分大小写的标准 AI 名称：`AI - Very Easy`、`AI - Easy`、`AI - Medium`、`AI - Hard`、`AI - Very Hard`、`AI - Impossible`；首尾空格会忽略。
- 自动识别只修改当前记录为人类的队伍，不会改动已经是 AI 的队伍。
- 存档中已有真实 AI 运行数据时，程序不会尝试将其转回人类，以免删除基地或作战小组等数据。
- 支持存档格式版本 23 及以上。无法识别或不受支持的文件不会被写回。

## 工作原理

联机客户端保存的存档会把主机上的 AI 记录为普通人类队伍，并且不包含 AI 运行状态。修复时，程序将队伍类型改为 AI，并写入一个空的初始 AI 状态；游戏在单人模式载入后会初始化 AI 状态。
